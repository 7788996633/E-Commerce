🛍️ Flutter Ecommerce App
This is a Flutter-based online store application developed with a clean, maintainable architecture and scalable code structure. It supports two user roles with dedicated functionality for each.

📱 About the Project
This application offers a basic e-commerce experience with the ability to:

Search and browse products

View product categories

Add products to a shopping cart

Mark products as favorites

There are two types of users:

Admin: Can manage the product catalog and approve orders.

User: Can browse products, add them to their cart, and make purchases.

The app follows clean code principles and uses the Provider package for efficient and reactive state management.

🛠️ Key Features
Product search and category filtering

Shopping cart management

Favorite products feature

Role-based access (Admin / User)

Clean architecture and organized project structure

State management using Provider

Ready for integration with backend systems
